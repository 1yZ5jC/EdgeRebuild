# Windows 10 1809（10.0.17763）回归复验清单

适用版本：里程碑 7.8 / R5-4 之后。
最低目标平台保持 `10.0.17763.0`，本清单用于在**真实 1809 设备或 1809 虚拟机**上确认
18362+ 专属 API（`XamlRoot`、`AppWindow`、`WindowManagement`）全部走兼容分支，且核心功能无回归。

> 说明：开发机（Win10 19041+ / Win11）只能通过
> `EDGEREBUILD_FORCE_LEGACY_WINDOW=1` 或设置 → 调试 → “强制 17763 兼容窗口”模拟部分路径，
> **不能替代真机复验**。本清单中的结果栏由执行人填写。

## 1. 安装、启动与退出

- [ ] 全新安装成功，开始菜单可启动。
- [ ] 首次启动完成数据库建表，无崩溃、无空白窗口。
- [ ] 冷启动进入主窗口；`LocalState\crash.log` 无未处理异常（启动计时日志可保留）。
- [ ] 关闭主窗口后进程退出干净；再次启动可正常打开。
- [ ] 卸载 / 覆盖升级安装后，旧数据库（收藏、历史、会话）仍可读取。

## 2. 窗口与 17763 兼容路径

1809 没有 `XamlRoot` / `AppWindow`，预期全部走 `PlatformCompat` 的 17763 分支：

- [ ] 主窗口尺寸、最大化 / 还原、全屏（F11）正常，窗口尺寸可跨重启恢复。
- [ ] 菜单“新建窗口”能打开副窗口；副窗口可独立导航、关闭。
- [ ] 拖出标签新建窗口成功，原窗口标签被移除，新窗口显示同一 URL。
- [ ] 多窗口快捷键只作用于焦点窗口（地址栏、Ctrl+T、Ctrl+W 等）。
- [ ] 副窗口不写入主会话；关闭副窗口后主窗口会话仍可恢复。
- [ ] 多显示器 / 不同 DPI 之间拖动窗口，布局与命中区域正常（无 0 尺寸或错位弹层）。
- [ ] `EDGEREBUILD_FORCE_LEGACY_WINDOW=1` 启动时行为与默认 1809 路径一致（回归对照）。
- [ ] 设置 → 调试 → “强制 17763 兼容窗口”切换并重启后，窗口仍能正常创建。
- [ ] 无任何 “找不到 Windows.UI.Xaml.XamlRoot / AppWindow” 类型加载异常。

- [ ] 固定 / 取消固定；固定标签宽度与位置正确。
- [ ] 拖拽排序（水平标签条）；拖出阈值判定正常，不会误分离。
- [ ] 中键关闭标签；右键菜单“关闭其他 / 关闭右侧 / 移动到新窗口”正常。
- [ ] 标签悬停缩略图在首次激活后出现；后台懒标签显示占位，不阻塞 UI。
- [ ] 标签预览带展开 / 收起、滚动、点击切换正常。
- [ ] 垂直标签侧栏切换、滚动、拖拽排序、固定正常。
- [ ] **快速切换**：Ctrl+Shift+A 在工具栏、地址栏、网页焦点三种场景均可打开。
  - [ ] 按标题 / URL 过滤；↑↓ 循环；Enter 切换；Esc / 点击面板外关闭。
  - [ ] 当前标签有“（当前）”标注；无匹配时回车不关闭。
  - [ ] 中文输入法组词期间方向键 / 回车不被面板截获。
- [ ] 会话恢复：重启后标签顺序、固定状态、当前标签正确；后台标签首次点击才加载。
- [ ] 强制结束进程后重启，会话可恢复（懒恢复占位标题可接受）。

## 12. 已知 1809 限制（非缺陷）

- 无 `AppWindow`：多窗口走 `CoreApplication.CreateNewView` 原生独立视图；失败时按现有回退链处理。
- 无 `XamlRoot`：`ContentDialog` / `Popup` 依附当前 `Window.Current` 视图；跨窗口弹层需确认落在正确窗口。
- WebView2 需要单独安装 Runtime；未安装时 WebView2 标签与 PDF 阅读器不可用，应给出提示。
- EdgeHTML 为系统旧内核，现代站点兼容性有限，可切换 WebView2。
